# Component Commons

A public catalog of UI recreations with live examples, code, and original source credits.

[Browse the catalog](https://component-commons.vercel.app/design-system/collected) · [Contribute a component](CONTRIBUTING.md)

## Run locally

Install Node.js 22 or newer, then run:

```sh
npm ci
npm run dev
```

Open `http://localhost:3000/design-system/collected`. Run `npm run lint && npm run build` before submitting a change.
